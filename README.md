# 🎓 SchoolEvents

**SchoolEvents** — это современное мобильное приложение для школьников и организаторов, предназначенное для удобного управления школьными мероприятиями и новостями. Приложение помогает сообществу быть в курсе всех событий, подписываться на ивенты и следить за последними новостями.

---

## ✨ Основные возможности

### 📱 Для студентов:
*   **Умная лента мероприятий:** Просмотр актуальных событий в разных форматах (горизонтальный скролл для популярных и вертикальный список).
*   **Навигация свайпами:** Плавное переключение между разделами («Исследовать», «Новости», «События») с помощью жестов (HorizontalPager).
*   **Избранное:** Сохранение интересных мероприятий в личный список.
*   **Новости:** Отдельная вертикальная лента с важными школьными объявлениями.

### 🛠 Для организаторов:
*   **Конструктор мероприятий:** Пошаговая форма создания ивентов с валидацией данных.
*   **Модерация:** Визуальные статусы для отслеживания состояния заявок (**"НА ПРОВЕРКЕ"**, **"ОТКЛОНЕНО"**).
*   **Архив событий:** Автоматическое отображение статуса **"ЗАКОНЧЕНО"** для прошедших мероприятий.
*   **Календарь и время:** Удобный выбор даты с защитой от ошибок (нельзя выбрать прошедшие даты).
*   **Управление контентом:** Возможность редактирования уже созданных событий и обновления фотографий.

### 🛠 Для директора:
*   **Модерация:** Возможность модерировать мероприятия.

## 🛠 Технологический стек

Проект построен на передовых инструментах разработки под Android:

*   **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) — полностью декларативный интерфейс.
*   **Архитектура:** MVVM (Model-View-ViewModel) с четким разделением слоев (Domain/Data/Presentation).
*   **DI:** [Hilt](https://developer.android.com/training/dependency-injection/hilt-android) — управление зависимостями.
*   **Навигация:** [Compose Navigation](https://developer.android.com/jetpack/compose/navigation).
*   **Загрузка изображений:** [Coil 3](https://coil-kt.github.io/coil/) (с поддержкой сетевых запросов и кэширования).
*   **Хранение данных:** [Room](https://developer.android.com/training/data-storage/room) (SQLite) и [DataStore](https://developer.android.com/topic/libraries/architecture/datastore).
*   **Дизайн:** Material 3, кастомные шрифты и полная поддержка **темной темы**.

---

## 🎨 Особенности интерфейса

*   **Edge-to-Edge:** Интерфейс отрисовывается под системными панелями (статус-бар и навигация) для максимального погружения.
*   **Адаптивность:** Корректное отображение на различных размерах экранов.
*   **UX-фишки:** Использование `HorizontalPager` для синхронизации вкладок и жестов свайпа.
